# 测试说明

## 自动检查

运行 `npm test`。使用 Node.js 内置 test runner，无需安装依赖。

覆盖：Manifest 引用文件、离线页面不依赖外部脚本、二维码库基础编码、提取相对链接与去重、跳过不支持的协议、同源 iframe / 开放 Shadow DOM、悬停恢复、点击保留、搜索、自定义输入、容量边界和受限页面回退。

此前已使用独立 jsQR 解码器对二维码像素进行网址及中文内容的解码验证。

## 真实浏览器验收清单

以下清单需要在 Chrome 加载扩展后执行，不代表已自动通过：

- [ ] 在 `chrome://extensions` 加载 `extension/`，确认没有 Manifest 或运行错误。
- [ ] 打开有多个链接的网页，点击扩展，检查当前页二维码和链接列表。
- [ ] 悬停 / 键盘聚焦链接，移开后恢复；点击后保留对应二维码。
- [ ] 手机扫码核对网址和中文文字。
- [ ] 下载 PNG、SVG 并打开，核对内容、背景和边距。
- [ ] 输入空内容及超长内容，确认下载按钮禁用并有合适提示。
- [ ] 搜索链接，页面更新后刷新。
- [ ] 打开 Chrome 内部页面，确认手动输入仍可使用。
- [ ] 允许访问文件网址后，检查本地 HTML 链接读取。
- [ ] 断网后打开 `docs/index.html`，检查生成及下载。

当前执行环境曾无法启动 Chrome 自动化，因此公开项目保留此验收边界，不宣称完成了所有真实浏览器测试。
