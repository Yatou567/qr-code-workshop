# 二维码工坊 · Chrome 扩展

## 安装

1. 解压「qr-code-workshop-chrome.zip」，保留整个文件夹。
2. 打开 Chrome，在地址栏输入 `chrome://extensions`。
3. 打开右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择包含 manifest.json 的「extension」文件夹。
5. 点击浏览器工具栏的拼图图标，将「二维码工坊 · 网页链接助手」固定到工具栏。

安装之后请保留扩展文件夹，移动或删除文件可能使扩展失效。本扩展为本地加载版本，未发布到 Chrome 应用商店。

## 使用

- 打开任意普通网页，再点击工具栏中的扩展图标。
- 弹窗会自动显示当前网页地址的二维码，并读取该页面中的链接。
- 鼠标悬停在弹窗中的「当前网页」卡片或链接条目上即可预览对应二维码；移开后恢复之前保留的二维码。
- 点击链接条目即可保留其二维码，再点击「下载 PNG」或「下载 SVG」。不会跳转到该链接。
- 左侧输入框支持网址、中文、普通文字，输入后实时生成，原始内容不会被自动修改。
- 可按链接名称或网址搜索；网页内容更新后，点击「刷新」重新读取。
- 键盘 Tab 聚焦链接同样可以预览，Enter 保留。

这里的悬停预览发生在插件弹窗内。Chrome 工具栏图标需要先点击打开弹窗。

## 读取范围与权限

使用 activeTab、scripting、storage、clipboardWrite 权限，在用户打开插件时临时读取当前页面。无需账户，无联网请求，不上传内容，成功生成的内容、来源类型和时间保存在本机历史，可删除，不云同步。

读取 HTML 链接（a/area 的 href），解析相对地址并按完整地址去重，支持 HTTP、HTTPS、mailto、tel、FTP、file 链接。包括可访问的同源 iframe 和开放 Shadow DOM。单次最多 5000 个不同链接。

跨域 iframe、封闭 Shadow DOM、尚未加载的内容、仅通过 JavaScript 点击跳转但不含 href 的按钮，无法读取。Chrome 内部页面、Chrome 应用商店等可能禁止脚本读取；仍可生成浏览器提供的当前页面地址或手动输入内容。部分地址仅适用于原设备，手机不一定能打开。

读取本地 HTML 的链接时，请在扩展「详情」页开启「允许访问文件网址」。二维码周围白色边距应保留。下载 PNG 为 1024×1024 像素；SVG 可无损缩放。生成过程离线可用，扫描后的联网访问另需网络。

已进行 JavaScript 语法检查和逻辑测试：链接提取、相对地址解析、去重、协议过滤、悬停/恢复、点击保留、搜索、空输入/超长输入、受限页面回退和异步读取期间输入保护。已从二维码像素解码校验网址与中文内容。

## 第三方组件

新增功能：点击「历史记录」查看、搜索或删除已生成内容；点击「选取元素」在网页上选择文字、链接或图片地址；点击「复制二维码」把图片粘贴到聊天或文档。元素模式按 Esc 退出。

升级至 1.1.0 时，在扩展页重新加载新文件夹并确认新增权限。若要保留已有数据，请覆盖原扩展目录后点刷新，不要卸载。
