# 隐私说明

适用于二维码工坊离线网页版与 Chrome 扩展 1.1.0。

## 处理哪些内容

离线网页版只处理你输入的内容。Chrome 扩展还会在你打开插件时读取当前标签页的网址、标题及页面链接，用于显示链接列表和二维码。

成功生成的二维码内容、来源类型和时间会保存在当前设备，最多 100 条并按内容去重。插件使用 chrome.storage.local，网页版使用 localStorage；不云同步、不上传。你可以在历史面板逐条删除或清空。元素选择只提取你点击的内容，不读取表单输入值。

## 权限用途

- `activeTab`：在用户打开扩展时获取当前标签页的临时访问权限。
- `scripting`：提取当前页面链接，并在你点击“选取元素”后显示选择浮层。
- `storage`：持久保存和删除本机二维码历史。
- `clipboardWrite`：点击复制按钮时向剪贴板写入二维码 PNG 图片；不读取剪贴板。

扩展未申请所有网站的持续访问权限，通过本地扩展服务工作线程协调历史写入，没有服务器接口、统计代码或第三方 CDN 请求。

## 下载与托管

下载的 PNG、SVG 包含你生成的内容，会由浏览器保存至你选择的位置。二维码本身不是加密或访问控制机制。

如果通过 GitHub Pages 访问网页版，页面分发由 GitHub 提供，遵循 GitHub 的服务及隐私政策；输入内容仍在浏览器内本地处理。下载单文件 HTML 后无需托管服务即可生成二维码。
